# Report notes

Use the files in `outputs/` to build the final IEEE/ACM-style report:

- Spider Execution Accuracy for base, Exp A, and Exp B.
- MMLU accuracy overall and by category.
- Delta Spider and MMLU against baseline.
- Two or three qualitative failure cases from `spider_predictions.jsonl`.
- Discussion of specialization, generalization loss, and benchmark contamination.

The final PDF is not generated automatically because it depends on the real Colab results.
